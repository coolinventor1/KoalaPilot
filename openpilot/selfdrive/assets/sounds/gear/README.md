# Gear-change prompts

These four prompts were imported from the HondaDash `src/assets` folder. The
source WAVs were 44.1 kHz stereo; the copies here are 48 kHz mono signed 16-bit
PCM for direct playback by openpilot's `soundd`.

The original `netural.wav` source filename is corrected to `neutral.wav` here.
